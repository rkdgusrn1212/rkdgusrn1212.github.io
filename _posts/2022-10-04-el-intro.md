## 1. EL이란?

*Expression Language*은 *JSF*와 *JSP*에서 *JavaBeans*의 동적 컨텐츠에 접근할 수 있는 간결한 표현식을 제공.

## 1.1. EL의 역사

- *ECMAScript*와 *XPath*의 영감을 받음.
- *JSP 1.2*의 *JSTL 1.0* 스펙의 일부로 *JSTL 액션*의 속성 값을 런타임에 입력하는 간결한 문법으로써 *EL*이 처음 등장.

  __"*JSTL 1.0*의 *EL*은 오직 *JSTL 액션*에서만 사용 가능했다"__

  > The JSP Standard Tag Library (JSTL) version 1.0 (based on JSP 1.2) was therefore first
to introduce an Expression Language (EL) to make it easy for page authors to access
and manipulate application data without having to master the complexity associated
with programming languages such as Java and JavaScript.


- *JSP 2.0*부터는 별도의 기술로 *JSP* 스펙에 포함 되었으며, *JSP*컨테이너 스스로가 *EL*표현식을 해석, *JSTL 액션*이외의 *커스텀 액션*, [*템플릿 데이터*](/java/java%20ee/jsp/2022/10/07/jsp.html#2-jsp-page의-구성)에서도 사용 가능해짐.

  __"*JSP 2.0*부터 기술 스펙에 등장한 *EL*은 *JSP*의 모든 부분에서 사용 가능하다"__

  > Given its success, the EL was subsequently moved into the JSP specification (JSP
2.0/JSTL 1.1), making it generally available within JSP pages (not just for attributes
of JSTL tag libraries).

- 기술 스펙은 [JSR-341](https://jcp.org/en/jsr/detail?id=341)에 기술.
- 마지막 버전은 *EL 3.0*, 이유는 [Jakarta EE](/java/java%20ee/jakarta%20ee/2022/10/04/jakarta-ee-intro.html) 참조.


  + 표현식의 *Deffered Evaluation*(지연된 평가)와 *Immediate Evaluation*(즉시 평가) 기능을 제공.
  + 표현식에서 *JavaBeans*의 데이터를 get하거나 set가능.
  + 표현식에서 메소드를 호출가능.

## 2. .

EL에서 표현식이 평가되는 시점은 Immediate Evaluation(즉시 평가)와 Deferred Evaluation(지연된 평가)로 나뉜다.

### 2.1. Immediate Evaluation(즉시 평가)

```
${표현식}
```

- *컴파일된 JSP 객체*가 실행되는 런타임에 바로 Evaluation수행.

### 2.2. Deferred Evaluation(지연된 평가)

```
#{표현식}
```

- 태그에 따라 정해진 시점에 Evaluation 수행.

## 3. 표현식의 종류

EL에서의 표현식은 크게 메소드를 호출하는 Method Expression(메소드 표현식)과 그렇지 않은 Value Expressions(값 표현식)으로 나뉠수 있다.


### 3.1. Value Expressions(값 표현식)

- 값 표현식은 *정적 텍스트*, 표현식을 허용하는 *태그 속성*에서 사용가능.
- 데이터 쓰기 가능 여부에 따라 R-value 표현식과 L-value 표현식로 나뉜다.

#### 3.1.1. R-value Expressions(R-value 표현식)

- 데이터 읽기만 가능.
- *Immediate Evaluation* 구문 ```${}``` 에 작성된 표현식은 모두 R-value 표현식이다.

#### 3.1.2. L-value Expressions(L-value 표현식)

- 데이터 읽고 쓰기 가능.
- L-value 표현식을 허용할 수 있는 태그 속성에서만 사용 가능.
