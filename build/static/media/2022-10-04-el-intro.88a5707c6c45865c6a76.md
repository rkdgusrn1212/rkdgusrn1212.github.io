## 1. EL이란?

*Expression Language*은 *JSF*와 *JSP*에서 *JavaBeans*의 동적 콘텐츠에 접근할 수 있는 간결한 표현식이다.

### 1.1 EL의 특징

- 기본적으로 `${expr}` 또는 `#{expr}` 구분자를 통해 나타낸다.
- _JSP_ page의 *Action Elements*와 *Template Data*에서 사용.
- 표현식의 _Deffered Evaluation_(지연된 평가)와 _Immediate Evaluation_(즉시 평가) 기능을 제공.
- 표현식에서 *JavaBeans*의 데이터를 get하거나 set가능.
- 표현식에서 메소드를 호출가능.

### 1.2. EL의 역사

- *ECMAScript*와 *XPath*의 영감을 받음.
- *JSP 1.2*의 _JSTL 1.0_ 스펙의 일부로 *JSTL 액션*의 속성 값을 런타임에 입력하는 간결한 문법으로써 *EL*이 처음 등장.

  **"*JSTL 1.0*의 *EL*은 오직 *JSTL 액션*에서만 사용 가능했다"**

  > The JSP Standard Tag Library (JSTL) version 1.0 (based on JSP 1.2) was therefore first
  > to introduce an Expression Language (EL) to make it easy for page authors to access
  > and manipulate application data without having to master the complexity associated
  > with programming languages such as Java and JavaScript.

- *JSP 2.0*부터는 별도의 기술로 _JSP_ 스펙에 포함 되었으며, *JSP*컨테이너 스스로가 *EL*표현식을 해석, *JSTL 액션*이외의 _커스텀 액션_, [_템플릿 데이터_](/posts/9#2-jsp-page의-구성)에서도 사용 가능해짐.

  **"*JSP 2.0*부터 기술 스펙에 등장한 *EL*은 *JSP*의 모든 부분에서 사용 가능하다"**

  > Given its success, the EL was subsequently moved into the JSP specification (JSP
  > 2.0/JSTL 1.1), making it generally available within JSP pages (not just for attributes
  > of JSTL tag libraries).

### 1.3. EL의 스펙

- 기술 스펙은 [JSR-341](https://jcp.org/en/jsr/detail?id=341)에 기술.
- 마지막 버전은 _EL 3.0_, 이유는 [Jakarta EE](/posts/3) 참조.

## 2. EL표현식의 구분

_EL_ 표현식은 *Evaluation*시점, 메소드 호출여부, 값 쓰기 가능여부에 따라 구분되어 진다.

### 2.1. Evaluation 시점에 따른 구분

_Evaluation_ 시점에 따라 _Immediate Evaluation_(즉시 평가)와 _Deferred Evaluation_(지연된 평가)두가지를 가진다.

#### 2.1.1. Immediate Evaluation

*컴파일된 JSP 객체*가 실행되는 런타임에 바로 *Evaluation*수행.

```
${표현식}
```

#### 2.1.2. Deferred Evaluation

*태그*에 따라 정해진 시점에 _Evaluation_ 수행.

```
#{표현식}
```

### 2.2. 메소드 호출 여부에 따른 구분

*EL*에서의 표현식은 크게 메소드를 호출하는 *Method Expression(메소드 표현식)*과 그렇지 않은 *Value Expressions(값 표현식)*으로 나뉠 수 있다.

### 2.2.1. Value Expressions

- 값 표현식은 _템플릿 데이터_ 및 *Action Elements*에서 사용가능.
- 데이터 쓰기 가능 여부에 따라 *R-value 표현식*과 *L-value 표현식*로 나뉜다.

### 2.2.2. Method Expression

JSP에서 선언된 객체의 메소드 혹은 정적 메소드를 호출 가능

```
public class MyObject {

	public String getMessage(String message) {
		return "Hello "+message;
	}
}
```

```
<%
   MyObject obj = new MyObject();
   request.setAttribute("obj", obj);
%>

${obj.getMessage("world!") }
```

### 2.3. 쓰기가능 여부에 따른 구분

#### 2.3.1. R-value Expressions

- 데이터 읽기만 가능.
- _Immediate Evaluation_ 구문 `${}` 에서 작성된 표현식은 모두 R-value 표현식이다.

#### 3.1.2. L-value Expressions

- 데이터 읽고 쓰기 가능.
- L-value 표현식을 허용할 수 있는 태그 속성에서만 사용 가능.
